# rodeiaflix

**PASSAR PARA O BRANCH "MASTER" PARA TER ACESSO AO PROJETO**

NOME DO PROJETO : RODEIAFLIX

DESENVOLVERDOR: MARCO RODEIA

SOLUÇÃO / FUNCIONALIDADES: 
VER TRAILER DOS FILMES, ADICIONAR FILMES, EDITAR FILMES E REMOVER FILMES, CONCEDER PODER DE ADMINISTRADOR, CRIAR CONTA, LOGIN

TECNOLOGIAS UTILIZADAS:
HTML5, CSS3, JAVASCRIPT, PHP, MYSQL, XAMPP

ARQUITECTURA:
O NOME DAS PAGINAS .PHP RESUME ONDE ESTÁ CADA CODIGO E O QUE FAZ CADA CODIGO, POR EXEMPLO A PAGINA LOGIN.PHP SERÁ A PAGINA PARA FAZER O LOGIN NO SITE E AO MESMO TEMPO
O ELO DE LIGAÇÃO COM A BASE DE DADOS PARA ESSA FNCIONALIDADE, O PROJETO ESTÁ ESTRUTURADO ASSIM, DE FORMA SIMPLES E DE FACIL ENTENDIMENTO.

INSTALAÇÃO / EXECUÇÃO:
APENAS USAR O XAMPP LIGAR O APACHE E O MYSQL, IMPORTAR A BASE DE DADOS PARA O MYSQL E DE RESTO VISUALIZAR O PROJETO TODO NA PASTA HTDOCS DO XAMPP E ACEDER NO BROWSER A
"http://localhost/rodeiaflix/index.php" DEPOIS DE TER IMPORTADO A BASE DE DADOS.

EXEMPLOS DE UTILIZAÇÃO / POSSIVEIS DESENVOLVIMENTOS FUTUROS:
ESTE SITE É PARA VER OS FILMES QUE ESTÃO NA PLATAFORMA E PARA GERENCIAR QUEM VÊ O CATALOGO DE FILMES E LIMITAR ESSE ACESSO POR VIA DE UMA PAGINA DE LOGIN, BASTANTE
UTIL PARA QUEM QUER PROTEGER ALGUNS VIDEOS OU MESMO PARA UM MODELO DE NEGOCIO ESTILO NETFLIX, TUDO DEPENDE DE COMO USAR ESTE PROTOTIPO.
